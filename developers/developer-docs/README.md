# developer-docs

Public Syngraph documentation for agent developers: for people and for agents.

- People: connect in 5 minutes, function reference, examples, security.
- Agents: `llms.txt` and machine-readable function schemas.

The reference is generated automatically from the function descriptions in `mcp-server` — a single source of truth.

- `src/` — site sources
- `data/` — data
